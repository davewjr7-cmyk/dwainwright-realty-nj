# David Wainwright Jr — RE/MAX Select — Static Website (Netlify-ready)

A static recreation of **dwainwrightrealty.com**, rebuilt as clean HTML/CSS/JS so it can be
hosted on **Netlify** (or any static host) after moving off Lofty.

## What's here

- Same layout, branding, fonts (Raleway), gold accent (`#ffc03a`) and page structure as the original.
- Every page recreated: Home, Buy/Listings, Featured, Sold, three calculators, Sell, REO Services
  (+ 7 sub-pages), Commercial, Market Insights (blog) with all posts, Contact, and a 404 page.
- Clean URLs via `folder/index.html` (e.g. `/sell`, `/reo-services/bpo-services`) matching the original paths.
- A working **Contact form** wired for Netlify Forms.
- `netlify.toml`, `robots.txt`, `sitemap.xml` included.

## Deploy to Netlify (drag & drop — easiest)

1. Go to https://app.netlify.com/drop
2. Drag this entire folder onto the page.
3. Netlify gives you a live URL in seconds. (You can add a custom domain under Site settings → Domain.)

## Deploy to Netlify (via Git — recommended long-term)

1. Put this folder in a Git repo (GitHub/GitLab).
2. In Netlify: **Add new site → Import an existing project**, pick the repo.
3. Build command: *(none)* · Publish directory: `.`

## Important notes

- **Images:** photos, the hero video, logo and badges currently load from the original
  Chime/Lofty CDN (the exact same URLs the live site uses). They will display correctly in any
  browser. To fully self-host them (recommended before you cancel Lofty), download the files and
  drop them into `assets/img/`, then update the URLs in `build_pages.py` / the HTML. Ask and I can
  help localize them.
- **Live listings & calculators** are shown as **visual placeholders** (per your request). To make
  them live, connect an IDX/MLS provider (GSMLS / Monmouth-Ocean) and a mortgage widget.
- **Contact form:** works automatically once deployed to Netlify (submissions appear under
  *Forms* in your Netlify dashboard). Update the notification email there.
- **Social links** in the footer point to `#` — replace with the real profile URLs.
- After deploy, update `YOUR-SITE.netlify.app` in `robots.txt` and `sitemap.xml` with your real domain.

## Editing

The site is generated by `build.py` + `build_pages.py` (Python, no dependencies). Edit content there
and run `python3 build.py`, or just edit the HTML in each `index.html` directly.
